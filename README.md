🚀 HOW TO ENTER THE DOMAIN?

No cursed energy required. Just follow these steps. 😭

1. Clone the repository

bash
git clone YOUR_REPOSITORY_LINK


2. Enter the project folder

bash
cd Quiz-Game-C


3. Compile the code

bash
gcc quiz.c -o quiz


4. START THE BATTLE!

bash
./quiz


For Windows:

bash
quiz.exe
